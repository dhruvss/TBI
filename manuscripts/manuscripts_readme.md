# Manuscript Files

This folder contains manuscript-related files for the preprint and related submissions.

Files may include:
- Final manuscript PDF
- Supplementary information PDF
- LaTeX source files, if included
- Bibliography files
- Submission-ready figure or manuscript exports

LaTeX compile artifacts such as `.aux`, `.log`, `.out`, `.toc`, and `.synctex.gz` should generally not be tracked in the repository.

The manuscript describes an in silico prioritization workflow for haloalkylated emapunil-derived TSPO PET tracer candidates for traumatic brain injury neuroinflammation.
