# Prespecified PBPK ranking sensitivity analysis

This directory contains the deterministic eight-scenario sensitivity analysis
generated by `PKSim/scripts/analyze_pbpk_weight_sensitivity.py`.

The 17 analogs define fixed component z-scores using sample standard deviations
(`ddof=1`). `AC5216_ref` is scored from those analog-defined z-scores but is
excluded from primary rankings and correlations. Docking is represented as the
desirability component `-z(dock_score)` with a nonnegative scenario weight.
Washout penalty definitions are unchanged across scenarios.

Ranks are ordinal: scores are sorted descending, ties are resolved by
`ligand_id` ascending, and ranks 1 through 17 are assigned. Spearman rho is
calculated directly as the Pearson correlation of baseline and scenario rank
vectors; no p-values or other hypothesis tests are calculated.

No random perturbation, Monte Carlo sampling, optimization, composite
robustness score, or significance analysis is used.
