# Figures

This folder contains figures generated for the manuscript and supplementary documentation.

Figures include workflow diagrams, scoring schematics, pharmacokinetic comparisons, lead-candidate plots, structure visualizations, and Logan analysis outputs. Some plots were generated from processed CSV outputs and finalized using GraphPad Prism.

Files in this folder may include:
- Manuscript-ready figures
- GraphPad Prism-exported plots
- Pipeline diagrams
- Docking or molecular visualization images
- Archived intermediate figures

Only final figures used in the manuscript should be treated as publication-ready. Intermediate or exploratory figures are retained only for documentation and reproducibility.
