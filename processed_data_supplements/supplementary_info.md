# Processed Data and Supplementary Tables

This folder contains processed data files used as supplementary tables for the manuscript.

Supplementary tables include:

- Supplementary Table S1: Full enumerated analog library containing the retained emapunil analogs, SMILES strings, enumeration metadata, physicochemical descriptors, CNS-MPO scores, docking scores, and gate status.
- Supplementary Table S2: Lead-candidate quality-control table documenting the 22 candidates advanced after screening, including duplicate-SMILES and CF/CF2 parsing exclusions.
- Supplementary Table S3: Final PBPK-screened candidate table containing the 17 retained lead analogs plus AC-5216 reference, including PBPK metrics, brain:plasma ratios, washout metrics, Kp, and final weighted score.

These files are intended to provide machine-readable support for the manuscript results and should be cited alongside the preprint.
