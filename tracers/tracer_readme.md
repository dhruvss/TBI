# Reference Tracer Conformations

This folder contains reference TSPO tracer structures and conformations used for baseline docking and comparison against the emapunil-derived analog library.

Reference tracer conformations were retrieved from PubChem when available and prepared for docking simulations. These files were used to support the initial reference-tracer comparison stage, in which existing TSPO PET tracers were ranked using physicochemical, PET kinetic, and docking-derived metrics.

Files in this folder may include:
- PubChem-derived 3D conformations for reference TSPO tracers
- Prepared ligand structures
- Ligand files converted for AutoDock Vina docking
- Intermediate conformer preparation files

The reference tracer set includes established TSPO PET tracers such as PK11195, PBR28, PBR06, PBR111, DPA-713, GE-180, DAA1106, and AC-5216/emapunil, depending on data availability and downstream scoring eligibility.

These structures were used for computational comparison only and should not be interpreted as experimentally validated conformational ensembles.
